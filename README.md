# Insta Story Gallery

Project concept for a local photo and video gallery. The poster is a design mockup, not a screenshot of a completed application.

## Windows CMD

```bat
git clone https://github.com/RuslanSharifov/insta-story-gallery.git
cd insta-story-gallery
```

## Android Termux

```sh
pkg update
pkg install git python
git clone https://github.com/RuslanSharifov/insta-story-gallery.git
cd insta-story-gallery
```

> Start commands and dependencies can be documented once the implementation is added. Never share browser session cookies or publish credential files.
